How to use:

Open the executable, and enter what model you want to use (1, 2, 3, 4, etc.) and press enter.
Once you have done that, enter a number you want the AI to guess. A number between 1 and 1000 is required. You may use a previous neural network map stored in '/neural' by typing "1" when prompted and typing the exact file name of your stored map. (e.g. model3_trained.json)

After that, you're all set to train your own AI to learn how to guess numbers.
